# Control Financiero

Aplicación web para gestión de finanzas personales con autenticación en Firebase, almacenamiento en Firestore y asistencia de IA con Gemini.

## Documentación técnica

La documentación técnica detallada del proyecto se encuentra en:

- [`docs/DOCUMENTACION_TECNICA.md`](docs/DOCUMENTACION_TECNICA.md)

## Ejecución local

**Prerequisitos:** Node.js

1. Instala dependencias:
   ```bash
   npm install
   ```
2. Crea `.env.local` y define `GEMINI_API_KEY`.
3. Ejecuta la app:
   ```bash
   npm run dev
   ```

## Scripts disponibles

- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`
